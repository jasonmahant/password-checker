# Password Strength Checker

A command-line tool written in C that analyzes the strength of a password.

## Features
- Checks password length
- Detects uppercase and lowercase letters
- Detects numbers and special characters
- Rates password as Weak, Moderate, or Strong
- Provides tips to improve weak passwords

## How to Run

### Compile
gcc password_checker.c -o password_checker

### Run
./password_checker

## Technologies
- C Programming Language
- GCC Compiler
